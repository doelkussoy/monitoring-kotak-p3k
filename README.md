# P3K Digital Monitoring System (CBA)

P3K Digital Monitoring System adalah aplikasi berbasis web yang dirancang untuk mengelola dan memantau persediaan kotak P3K (First Aid Kit) di seluruh area perusahaan secara terpusat. Aplikasi ini membantu tim kesehatan/keselamatan dalam mencatat pemeriksaan rutin, stok barang, dan masa kadaluarsa obat-obatan.

## Fitur Utama
*   **Modern Dashboard**: Tampilan premium dengan statistik real-time (Total Lokasi, Kondisi Kritis, Health Capacity).
*   **Inventory Management**: Pemantauan stok dan masa kadaluarsa tiap item di setiap lokasi P3K.
*   **Activity Timeline**: Log aktivitas pemeliharaan dan pembaruan stok secara otomatis.
*   **Responsive Design**: Dapat diakses dengan nyaman melalui desktop maupun perangkat mobile.

## Teknologi
*   PHP (Native)
*   MySQL/MariaDB
*   Bootstrap 5.3
*   Lucide Icons
*   Glassmorphism CSS Design

## Instalasi
1.  Clone repository ini ke direktori `htdocs`.
2.  Pastikan server MySQL berjalan.
3.  Konfigurasi database pada file `db.php`.
4.  Akses aplikasi melalui browser (default: `index.php`).
